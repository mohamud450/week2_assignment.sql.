# Week 2 Assignment: Introduction to SQL

## Contents
- `week2_assignment.sql` — SQL queries for all five assignment questions.

## Before running the queries
1. Import the provided `sales` database into MySQL.
2. Open MySQL Workbench (or your MySQL terminal).
3. Open `week2_assignment.sql`.
4. Execute the script.

The script selects the `sales` database with `USE sales;` before running the queries.

## Assignment questions covered
1. Select payment check number, payment date, and amount.
2. Find orders with status `In Process`, newest order date first.
3. Find employees with job title `Sales Rep`, highest employee number first.
4. Select every column and row from `offices`.
5. Show the five products with the lowest `buyPrice`, including product name and quantity in stock.

## Note
This ZIP contains the SQL answers, not the database itself. The `sales` database must be imported separately using the course-provided database files.
